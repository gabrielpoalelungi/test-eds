# search-restaurant

Custom **search** block. Purpose: store-finder placeholder: labelled search input that sends users to the restaurant locator page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = label / placeholder text (e.g. "Găsește un restaurant"); row 2 = link to the restaurant locator (e.g. /restaurante). The typed text is appended as ?q=. The block renders a white pill with a search icon, a red submit arrow and a "Folosește locația mea" location button; the location button opens the locator link (no live lookup or geolocation).
