# carousel-hero

Custom **carousel** block. Purpose: full-width promotional hero slider at the top of the home page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1 = image only; cell 2 = heading, paragraph, CTA link, optional small-print disclaimer paragraph(s) after the CTA.

## Behaviour

- CTA links become white KFC pills (`kfc-button is-white`) with the block's `storefront.svg` / `arrow-right.svg` icons.
- Small print after the CTA is pinned to the bottom of the slide (desktop).
- Autoplay every 10s (wraps to the first slide), stopped on any user interaction or when reduced motion is preferred.

No variations.
