# cards-product

Custom **cards** block. Purpose: grid of product cards with badge, title, description, details link and image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per product; cell 1 = product image only; cell 2 = optional badge paragraph (e.g. "Nou") before the title, title (heading or bold paragraph), description, details link.
